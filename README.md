# Respondi

SaaS multi-tenant de atención al cliente y ventas por IA (WhatsApp,
Instagram, Facebook) para equipos comerciales/de atención al cliente.

## Stack
Next.js + TypeScript + Tailwind CSS · Supabase (PostgreSQL + RLS +
Realtime) · Vercel · n8n como conector de mensajería.

## Desarrollo
```bash
npm install
npm run dev
```
Abre [http://localhost:3000](http://localhost:3000).
